How to Import Students
1 Download Template

Download the Excel template with the correct format and sample data.

2 Fill Your Data

Replace the sample data with your student information. Keep the column headers unchanged.

3 Upload & Import

Upload your completed Excel file to import all students at once.

Required Columns:
  • enrollment_no - Unique student ID
  • student_name - Full name
  • school - School/College name
  • branch - Department/Branch
Optional columns: semester, email, phone, year_of_admission

Import Guidelines:
  • Enrollment numbers must be unique (duplicates will be skipped)
  • Existing students with same enrollment number will not be overwritten
  • Empty rows will be automatically skipped
  • Maximum recommended file size: 5MB (~10,000 students)
  • All import errors will be displayed after processing
