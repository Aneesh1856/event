Import Format Requirements:
Required Columns (case-sensitive):
• Teacher Username - Must match existing teacher usernames exactly
• Day - Must be exactly one of: monday, tuesday, wednesday, thursday, friday, saturday, sunday (lowercase only)
• Time Slot - Format: HH:MM-HH:MM (e.g., 9:00-9:50)
• Subject Code - Must be assigned to the teacher
• Section - Must exist for the subject
• Class Type - theory, lab, or other

IMPORTANT:
• Use separate rows for each class (do NOT put multiple days in one cell)
• Days must be lowercase (use "monday" not "Monday")
• Each row = one class period for one teacher on one day
